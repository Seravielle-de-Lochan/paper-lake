# Paper Lake

A night lake in cut paper, drawn behind the conversation in the Claude desktop app.

Pines stand in three depths against a starry sky with a layered paper moon. The lake is five strips of teal paper drifting slowly against each other. Frogs sit on lily pads. They blink and breathe, their throats puff, and the big one hops now and then. A pink water lily slowly opens and closes, and cattails sway in the corners. Rain comes and goes in waves, rippling the water, and every so often a star falls and splashes into the lake.

Every piece is a scissor-cut shape laid down four times: a far shadow, a near shadow, a pale lip catching the light, then the paper itself. The middle of the sheet stays open water, so your words sit on calm paper. The app's own colours switch to a matching dark pond palette with frosted glass over the scene.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install paper-lake --marketplace Seravielle-de-Lochan/paper-lake
```

Answer `y` to add the marketplace, then choose a scope.

From a shell:

```bash
claude plugin install paper-lake --marketplace Seravielle-de-Lochan/paper-lake
```

In the desktop app: click **+** next to the prompt box, then **Plugins**, **Add marketplace** with `Seravielle-de-Lochan/paper-lake`, then **Add plugin**.

The scene draws in the Claude desktop and mobile apps. Terminals and editors don't draw backdrops.

## Commands

- `/lake` brings the lake back.
- `/lake-off` puts it away. This clears whatever theme is showing.
